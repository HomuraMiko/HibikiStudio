Hibiki

An all-in-one broadcasting and content creation platform.

Hibiki is a standalone native C++ application built to replace the pile of separate tools most streamers deal with. Canvas compositing, spatial audio, shader effects, physics, media playback, and broadcasting — all in one place, no duct tape required.

What it does
Broadcasting — Stream and route audio without juggling extra software.
Canvas Compositing — Real-time layer-based scene composition built into the core.
Spatial Audio — HRTF-based 3D audio positioning for actual immersion.
Shader Effects — GPU-accelerated visual effects that don’t tank your performance.
Physics Interactions — Dynamic physics-driven elements because why not.
Media Playback — Integrated media handling baked into the workflow.
Current State

This is an early release. Known limitations:

NVENC only — no other encoders supported yet.
Stream/VOD audio separation is not working correctly.
Some features are barebones or partially implemented. (specially Clean list and Sloppy Springs mode in Viewer Chat element)

Ship it anyway.
